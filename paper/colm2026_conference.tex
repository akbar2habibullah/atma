\begin{abstract}
Evaluating zero-shot sequence length extrapolation requires balancing soft-attentional retrieval fidelity, long-document likelihood stability, and inference compute efficiency. We introduce \textbf{ATMA}, a hybrid architecture whose Polar Attention layer decomposes sequence mixing into a radially normalized direction channel, a bounded participation-ratio magnitude channel, and a recurrent gated-delta memory channel. Rather than claiming universal architectural dominance, we frame long-context sequence modeling as an empirical Pareto frontier. Through a 120-run, 1B-token factorial sweep and a matched 10B-token study across 378M-parameter NoPE, RoPE, Polar, and stateful Raven baselines evaluated out to 256K tokens, we demonstrate that Polar establishes a favorable Pareto trade-off: it preserves high-fidelity soft retrieval across natural text (16.3\% real-text retrieval accuracy at 64K vs 0.0\% for NoPE/RoPE) and maintains long-document stability (1.26$\times$ bits-per-byte inflation at 256K vs 5.65$\times$ for NoPE) at a modest short-context expressivity trade-off (~1.5\% mean zero-shot task penalty). Crucially, our controlled diagnostics uncover a striking empirical warning for the long-context research community: \textbf{short-context pretraining convergence is completely blind to long-context extrapolation collapse}. Identical 2K pretraining validation loss trajectories ($<0.01\%$ difference across 10B tokens) mask catastrophic 256K context divergences (4.07 vs 10.77 nats NLL) when trained across different hardware environments (NVIDIA L4 vs L40S) due to lower-level CUDA kernel reduction order and floating-point accumulation order. We issue a call-to-action for long-context research to adopt multi-hardware environment auditing protocols alongside architectural reporting.
\end{abstract}

The capacity of Large Language Models (LLMs) to ingest, process, and reason over massive context windows is a cornerstone of modern artificial intelligence capabilities. Applications ranging from repository-level code synthesis to complex academic document analysis depend on the model's ability to maintain coherent representations across tens of thousands of tokens. However, the standard sequence mixer, softmax scaled-dot-product attention (SDPA)~\citep{Vaswani+2017}, exhibits severe limitations when generalizing to sequence lengths beyond those encountered during training.

This failure of length extrapolation is consistent with a growing body of evidence on softmax dispersion in long contexts. Nakanishi~\citep{nakanishi2025scalable} observes that the maximum coordinate of a softmax vector approaches zero as the vector size increases, flattening attention as the context grows. Veli{\v{c}}kovi{\'c} et al.~\citep{velickovic2025softmax} prove that softmax-based lookup circuits for sharp decisions disperse as problem size increases, while Barbero et al.~\citep{barbero2024glasses} relate long-sequence failures to representational collapse and over-squashing in decoder-only Transformers. A complementary line of work uses extreme-value reasoning: Threshold Differential Attention (TDA)~\citep{huang2026threshold} argues that unrelated query-key pairs produce chance maxima that grow with context length, so fixed rectifier thresholds eventually admit spurious survivors. We use \textit{dilution} to refer to this dense-normalization effect: as the number of keys $N$ grows, probability mass is spread across a larger population, reducing the weight assigned to any fixed set of relevant keys unless logits sharpen with length. Softmax also entangles magnitude information (``how many items matched the query'') with direction information (``what features were matched'') into a single normalized output. These mechanisms motivate Polar Attention, but our stress results show that realized failure modes are checkpoint-dependent: one softmax checkpoint amplifies a downstream mode, another attenuates its representations, and neither behavior is a universal consequence of RMS normalization alone.

Faced with this challenge, practitioners often employ Sliding Window Attention (SWA)~\citep{beltagy2020longformer} or Recurrent/Linear Attention alternatives~\citep{deltanet2024, mamba2023}. However, this introduces a severe trade-off:
\begin{itemize}
    \item \textbf{Sliding Window Attention} keeps the active key set bounded and can maintain local likelihood, but it is completely blind to retrieval targets located past the window boundary.
    \item \textbf{Full Softmax Attention} preserves explicit access to distant tokens, but its long-context behavior can become checkpoint-sensitive through probability dilution, representation attenuation, or downstream amplification.
    \item \textbf{Recurrent Fast-Weight Memories} act as lossy compression systems that carry general document flow, but lack the high-precision focus required to recall random, pinpoint facts (the ``needle-in-a-haystack'' problem) from a massive context.
\end{itemize}

We resolve this tension by introducing \textbf{ATMA}, a hybrid sequence-modeling architecture that merges the structural local-mixing advantages of gated depthwise convolutions with a novel three-channel attention layer. In ATMA, each attention layer decomposes its output into an additive combination of three distinct streams:
\begin{equation}
    \mathbf{out} = \mathbf{content} + \mathbf{count} + \mathbf{memory}
\end{equation}
The first two streams (\textbf{content} and \textbf{count}) form our proposed \textbf{Polar Attention} core. By radially normalizing the matched value-sum, the \textbf{content} channel represents \textit{what} matched with a bounded direction vector, while the \textbf{count} channel represents \textit{how much} matched through a bounded transform of the participation ratio (inverse Simpson index). Radial normalization removes aggregate scale, but the direction can still vary with the attention distribution and the learned null value. To prevent background noise from overwhelming the signal at extreme sequence lengths, Polar Attention calibrates its logits against a learned null floor parameterized on the extreme-value scale $\sqrt{\log n}$.

The third stream (\textbf{memory}) is a recurrent, per-head associative memory block driven by a gated-delta update rule, inspired by the Titans model~\citep{titans2025}. The linear memory behaves as a lossy gist that captures long-term likelihood trends, while Polar Attention supplies the bounded full-context readout needed for exact recall. The ablations show that neither ingredient is enough in isolation: memoryless Polar Attention still loses retrieval at long range, and softmax paired with the same memory collapses at extreme lengths.

Our empirical study evaluates long-context modeling as a multi-objective Pareto trade-off across two stages. A complete \textbf{120-run factorial sweep} at 1B tokens identifies the Polar-plus-memory recipe under a broad architectural grid. The main comparison then promotes that recipe to approximately 10B training tokens and evaluates matched NoPE, RoPE, and Polar attention variants, plus separate Raven sparse-memory baselines~\citep{raven2026}, on retrieval depth sweeps, BABILong reasoning~\citep{babilong2024}, base language-model tasks, fixed-target long-document likelihood, serving, and mechanistic stress tests through 256K tokens. The headline is deliberately multi-objective: Polar establishes a highly effective Pareto balance by excelling at soft-attentional retrieval and long-document likelihood stability; Raven achieves peak BABILong reasoning and $7.2\times$ faster decode latency via $O(1)$ state compression; and standard Softmax retains a slight edge on short 2K completion tasks. Crucially, our stress analysis uncovers a striking empirical warning: short-context pretraining convergence is completely blind to long-context extrapolation collapse. Identical 2K pretraining validation loss trajectories ($<0.01\%$ difference across 10B tokens) mask catastrophic 256K context divergences (4.07 vs 10.77 nats NLL) when trained across GPU device classes (L4 vs L40S) due to lower-level CUDA kernel reduction order. We call on the community to report and audit multi-hardware environment sensitivity before attributing extrapolation traits purely to high-level architectural mechanics.

Our implementation is numerically cross-verified across pure-PyTorch, training, and paged-inference paths. We introduce a FlashAttention-style Triton kernel that streams the participation-ratio statistics in $O(\text{block})$ memory and wrap the gated-delta recurrence as opaque custom operations to avoid compiler graph breaks. The complete repository accompanying the paper contains the configurations, logs, checkpoint manifests, benchmark matrices, raw BABILong bundles, and stress summaries required to audit every reported number.

\section{Related Work}

\subsection{Softmax Attention and Scaling Limits}
Traditional Transformer architectures rely on softmax scaled-dot-product self-attention~\citep{Vaswani+2017}. While highly expressive, the $O(T^2)$ computational complexity has inspired numerous long-context extensions. Positional representations like Rotary Position Embeddings (RoPE)~\citep{rope2021} and Attention with Linear Biases (ALiBi)~\citep{alibi2021} allow models to extrapolate position indicators to longer sequences. However, they do not directly alter the dense simplex normalization of softmax. Prior work has framed this as flattening, dispersion, or loss of sharpness: Scalable-Softmax rescales logits to counter the vanishing maximum softmax probability~\citep{nakanishi2025scalable}; adaptive-temperature analyses show that softmax lookup circuits lose sharpness out-of-distribution as size grows~\citep{velickovic2025softmax}; and sparse-attention work proves that softmax distributions become increasingly dispersed whereas entmax can retain nonzero probability on a fixed relevant set~\citep{vasylenko2026sparse}. Sliding Window Attention (SWA)~\citep{beltagy2020longformer} avoids this dilution by truncating the attention context, but permanently sacrifices long-range recall.

\subsection{Extreme-Value-Aware Attention}
TDA~\citep{huang2026threshold} provides a direct theoretical reference point for the noise side of long-context attention. Under a sub-Gaussian noise model for unrelated query-key scores, the maximum spurious score over $n$ keys grows on the order of $\sqrt{\log n}$; TDA therefore sets a row-wise threshold $\tau_i \propto \sqrt{2\log i / d}$ and keeps only rectified exceedances. This yields ultra-sparse, non-dispersive attention by controlling the expected number of spurious survivors per row, and the differential variant subtracts a second thresholded view to cancel common-mode noise. ATMA adopts the same extreme-value premise but makes a different architectural choice: rather than converting attention into hard exceedance filtering, Polar Attention keeps a softmax-style value readout and adds a learned, extreme-value-corrected null sink. This lets the model preserve a differentiable full-context direction channel while separately exposing a bounded participation-ratio magnitude channel.

\subsection{Linear Attention, State-Space Models, and Raven}
To achieve linear-time complexity, linear attention and State-Space Models (SSMs) reformulate attention by shifting the computation order of key, query, and value matrices~\citep{mamba2023,deltanet2024}. This reparametrization treats the sequence mixer as a recurrent neural network with a matrix-valued state. Recent architectures like Gated DeltaNet~\citep{deltanet2024} and Titans~\citep{titans2025} incorporate data-dependent gating and delta-rule updates to actively overwrite and retrieve memories.

\paragraph{Raven as a SOTA Sub-Quadratic Baseline.}
While foundational SSMs (such as Mamba, Mamba-2, and S4) and linear recurrences (such as RWKV and Gated DeltaNet) achieve sub-quadratic decode throughput via $O(1)$ state updates, basic un-routed linear recurrences suffer from lossy state compression bottlenecks when retrieving facts over long context windows. \textbf{Raven}~\citep{raven2026} represents a major state-of-the-art advancement over foundational SSMs and plain Gated DeltaNet layers. Raven unifies sparse routed memory, Swish feature maps, Mamba2-style decay dynamics, and Gated DeltaNet recurrence into a high-recall sub-quadratic architecture. Consequently, evaluating against Raven Native and the Atma-Raven-Titans hybrid provides a strictly stronger, state-of-the-art sub-quadratic baseline comparison than legacy SSMs (Mamba, S4) or un-routed linear recurrences.

\subsection{Hybrid Architectures and Canon Layers}
Recent work demonstrates that hybrid architectures combining local and global sequence mixers can outperform pure transformers on both efficiency and quality. Models like Mamba~\citep{mamba2023} and Liquid Foundation Models 2 (LFM2)~\citep{lfm2_2025} combine linear state-space models or gated convolutions with sparse attention layers. Furthermore, \citet{physics_lms_2025} show that incorporating depthwise causal convolutions (known as Canon layers) on the query, key, and value projections prior to scoring provides critical horizontal shift-covariance and spatial awareness. ATMA builds on these insights, adopting a 3:1 ratio of LFM2 convolutions to Polar Attention layers to maximize parameter efficiency and sequence throughput.

\section{Methodology}

\subsection{Architecture Overview}
ATMA is a 16-layer decoder-only language model designed with a 3:1 hybrid sequence-mixing ratio. Specifically, the architecture consists of 12 LFM2 gated convolutional layers and 4 Polar Attention layers. Each decoder block uses a pre-normalization layout:
\begin{align}
    x' &= x + \operatorname{SubLayer}(\operatorname{RMSNorm}(x)) \\
    x'' &= x' + \operatorname{MLP}(\operatorname{RMSNorm}(x'))
\end{align}
where the SubLayer is either an LFM2 gated convolution or a Polar Attention layer. The MLP block uses a squared-ReLU activation function with a 4$\times$ hidden dimension expansion:
\begin{equation}
    \operatorname{MLP}(z) = W_{\text{down}}\left( \operatorname{ReLU}(W_{\text{gate}} z)^2 \cdot (W_{\text{up}} z) \right)
\end{equation}
By keeping the attention footprint sparse (only 4 out of 16 layers), ATMA maintains low computational overhead while leveraging the global mixing capacity of Polar Attention and Titans memory.

\subsection{Polar Attention}
Polar Attention is designed as a length-robust alternative to softmax scaled-dot-product attention. It operates within the standard Grouped-Query Attention (GQA) framework, with $H$ query heads and $H_{\text{KV}} = H / 4$ key-value heads. Prior to scoring, the horizontal residual causal convolutions (Canon layers) are applied to the $q$, $k$, and $v$ projections. We also apply RMS-normalization to the queries and keys.

For a given query $i$ attending over keys $j < n_i$ (where $n_i = i + 1$), the raw scores are computed as:
\begin{equation}
    \sigma_{ij} = \frac{q_i \cdot k_j}{\sqrt{d_k}}
\end{equation}

\subsubsection{Length Temperature and Extreme-Value-Corrected Null Floor}
To prevent softmax dilution and resist extreme-value noise, we introduce per-head learned scalars that compute two sequence-length-aware quantities:
\begin{enumerate}
    \item \textbf{Length Temperature} $\mathrm{temp}_i$: Sharpens the attention distribution as context grows, preventing the probability mass from spreading too thin:
    \begin{equation}
        \mathrm{temp}_i = 1 + \operatorname{softplus}(\alpha) \cdot \log(n_i)
    \end{equation}
    where $\alpha$ is a learned head-specific scalar parameter (initialized raw to $-1.0$).
    \item \textbf{Extreme-Value-Corrected Null Floor} $\mathrm{null}_i$: Acts as the logit of a virtual ``null sink'' key. Because the maximum of $n$ random noise scores grows asymptotically like $\sqrt{2 \ln n}$, any fixed threshold is eventually overtaken by noise. We correct this by defining a growing floor:
    \begin{equation}
        \mathrm{null}_i = \text{null\_base} + \operatorname{softplus}(\gamma) \cdot \sqrt{\log(n_i + 1)}
    \end{equation}
    where $\text{null\_base}$ (init 2.0) and $\gamma$ (init raw 0.5) are learned per-head parameters.
\end{enumerate}
This null floor plays the same statistical role as the length-dependent exceedance threshold in TDA~\citep{huang2026threshold}: it rises with the extreme-value scale of unrelated scores. When its learned slope dominates the noise scale, background noise is prevented from winning merely because the context is longer. The distinction is operational. TDA discards sub-threshold keys and aggregates only sparse survivors; Polar Attention appends the null as an additional softmax competitor. Noise mass can therefore drain into the null sink while real-key weights remain available for the direction and magnitude channels below. Appendix~\ref{appendix:theory} gives sufficient conditions under which this null-sink odds ratio vanishes with context length and the full ATMA mixer remains bounded.

\subsubsection{Direction Channel (``What'')}
We append the null logit $\mathrm{null}_i$ to the real key-logits, apply softmax, and form a convex combination of the real values and a learned default null vector $v_{\text{null}} \in \mathbb{R}^{d_k}$:
\begin{align}
    w_i &= \operatorname{softmax}\left( \left[ \mathrm{temp}_i \cdot \sigma_{i\bullet}, \ \mathrm{temp}_i \cdot \mathrm{null}_i \right] \right) \\
    s_i &= \sum_{j} w_{ij} v_j + w_{iN} v_{\text{null}}
\end{align}
We then radially normalize $s_i$ to obtain the \textbf{direction} channel $c_i$:
\begin{equation}
    c_i = \frac{s_i}{\max(\|s_i\|_2,\varepsilon)}
\end{equation}
where $\varepsilon>0$ is a numerical stabilizer. Consequently $\|c_i\|_2\le 1$, with equality whenever $\|s_i\|_2\ge\varepsilon$. This removes radial activation scale from the content channel. It does not, by itself, make the direction independent of match count: changing the number or distribution of matches can change the real-key mixture and its balance with the learned null value. The separate magnitude channel below exposes a bounded summary of effective match count.

\subsubsection{Magnitude Channel (``How Much'')}
To represent \textit{how many} effective matches were found, we reuse the attention weights $w_i$. We first renormalize them over the real keys only, and then calculate the \textbf{participation ratio} $n_{\text{eff}}$ (which corresponds to the inverse Simpson index):
\begin{align}
    \hat{w}_{ij} &= \frac{w_{ij}}{\sum_k w_{ik}} \\
    n_{\text{eff}} &= \frac{1}{\sum_j \hat{w}_{ij}^2}
\end{align}
If 1,000 strong keys match, $n_{\text{eff}} \approx 1000$; if only noise is present, the length-aware temperature keeps $n_{\text{eff}}$ bounded. We gate this count by the confidence that real signal was found, $m_{\text{eff}} = n_{\text{eff}}(1 - w_{iN})$, and map it through a bounded, saturating monotonic function:
\begin{equation}
    \mathrm{mag}_i = \tanh\left( \operatorname{softplus}(\beta) \cdot \log(1 + m_{\text{eff}}) \right) \in [0, 1)
\end{equation}
This bounded map ensures that the magnitude channel input remains in-distribution at any context length (unlike raw $\log(m)$ which grows without bound).

\subsubsection{Assembly and Distractor Objective}
The direction and magnitude are recombined into the residual stream:
\begin{equation}
    \mathbf{out}_{\text{polar}} = W_o\left( \operatorname{reshape}(c) \cdot \sigma(\text{gate}) \right) + W_{\mu}(\mathrm{mag})
\end{equation}
where $\text{gate}$ is a sigmoid gating factor carried in the $q$ projection, $W_o$ is the output projection, and $W_{\mu}$ is a per-head additive projection.

To calibrate the null floor during training, we introduce an auxiliary \textbf{distractor loss} $\mathcal{L}_{\text{align}}$. A set of $R$ random keys are projected and scored, and they must lose to the null sink:
\begin{equation}
    \mathcal{L}_{\text{align}} = \operatorname{mean}\ \operatorname{softmax}\left( [ \mathrm{temp} \cdot \sigma_{\text{rand}}, \ \mathrm{temp} \cdot \mathrm{null} ] \right)\Big|_{\text{rand}}
\end{equation}
This loss (weighted by 0.01 when enabled) pushes random distractors below the null floor, widening the signal-to-noise margin $\Delta$. In the final ablation, however, the best Polar + memory configuration leaves this auxiliary objective disabled: once the recurrent memory branch is active, the distractor objective over-sharpens the null floor and hurts retrieval (Table~\ref{table:ablation_selection}).

\subsection{Titans Memory-as-Gate Integration}
While Polar Attention bounds the ranges of its direction and magnitude channels, a single attention core cannot solve the window-vs-retrieval trade-off alone. We incorporate a long-term recurrent memory as an additive third channel in the residual block:
\begin{equation}
    \mathbf{out} = \mathbf{out}_{\text{polar}} + \mathbf{out}_{\text{mem}}
\end{equation}

Each head maintains a matrix state $M \in \mathbb{R}^{d_v \times d_k}$ acting as a fast-weight associative key-value store. It reuses the layer's $q$, $k$, and $v$ projections, and derives two data-dependent gates per step from the layer input $x$:
\begin{align}
    \gamma_t &= \sigma(W_{\gamma} x_t + b_{\gamma}) \in (0, 1) \quad (\text{retention gate; } b_{\gamma} \text{ init } 3.9 \to \sigma \approx 0.98) \\
    \beta_t &= \sigma(W_{\beta} x_t + b_{\beta}) \in (0, 1) \quad (\text{write strength; } b_{\beta} \text{ init } 0.0 \to \sigma \approx 0.5)
\end{align}

\subsubsection{Gated-Delta Recurrence and Key Normalization}
The memory state is updated via a conditional gated-delta rule, which we implement following the Flash Linear Attention (FLA) library \citep{fla2024} canonical convention (decay-first, undecayed write, self-inclusive readout). Crucially, when momentum $\eta = 0$, the Titans neural memory reparametrizes exactly to a closed-loop Gated DeltaNet (GDN) recurrence \citep{yang2024gated}:
\begin{align}
    M_t &= \gamma_t \cdot M_{t-1} (I - \beta_t \cdot k_t k_t^{\top}) + \beta_t \cdot v_t k_t^{\top} \\
    r_t &= M_t \cdot q_t
\end{align}
This can be computed in an equivalent per-step online manner:
\begin{align}
    M &\leftarrow \gamma_t M \\
    \mathrm{pred} &= M k_t \\
    M &\leftarrow M + \beta_t (v_t - \mathrm{pred}) k_t^{\top} \\
    r_t &= M q_t
\end{align}

\textbf{Finding 1: Key Normalization.} The eigenvalue of the delta rule update along $k$ is $\gamma (1 - \beta \|k\|^2)$. Standard RMS-normalization yields $\|k\|^2 = d_k$, pushing the eigenvalue to $\approx -7$, which causes immediate exponential divergence (the state norm explodes to $\approx 10^{57}$). \textbf{We resolve this by applying $L_2$-normalization to the keys and queries} ($\|k\|_2 = 1$). Under the stated gate ranges, this keeps the one-step eigenvalue along $k$ in $(0,1)$; it does not by itself prove that the complete nonlinear network is contractive.

\textbf{Finding 2: Self-Stabilization.} Analysis of the recurrent scan reveals that the delta memory is self-stabilizing. Because the $(I - \beta k k^{\top})$ term continuously projects out old matched dimensions, the state norm remains completely flat across length sweeps even at $\gamma=1$. Gamma $\gamma$ behaves purely as a temporal-horizon dial (governing recency vs global memory), not a stability requirement.

\subsubsection{Readout Assembly}
The readout vector $r_t$ is normalized and gated before adding it to the residual stream:
\begin{equation}
    \mathbf{out}_{\text{mem}} = W_{\text{mem\_proj}}\left( \operatorname{RMSNorm}(r) \cdot \sigma(\operatorname{gate}_{\text{mem}}(x)) \right)
\end{equation}
We initialize $W_{\text{mem\_proj}}$ to zero so that the memory branch acts as a safe no-op at step 0 of training or when fine-tuning a pre-trained checkpoint.

\section{Experimental Setup}

\subsection{Stage I: Illustrative 1B-Token Recipe Selection}
The first stage is a complete $3\times5\times2\times2\times2=120$ cell factorial sweep. Every model has 16 layers (12 LFM2 gated convolutions and four attention layers), hidden size 1024, head dimension 128, eight query heads, two KV heads, and a 50,304-token GPT-2 vocabulary. The 369.7--378.2M-parameter models train for 1,900 steps of 524,288 tokens (approximately 1B tokens) at sequence length 2,048 on FineWeb-Edu. All use the same Muon/AdamW split optimizer and cosine schedule. The axes are attention type (Polar, RoPE, or NoPE), signature-stream regularization (five modes), distractor loss, gated-delta memory, and a 1,024-token attention window. The 120 jobs were distributed concurrently over four NVIDIA L4 machines; every cell completed without a logged error. This stage is used to choose a recipe, not to supply the paper's headline absolute results.

For each cell, we evaluate 16 coherent FinePDFs prefixes and 16 five-digit induction trials per length from 2K to 64K. The legacy log fields \texttt{clean\_ppl} and \texttt{junk\_ppl} store mean cross-entropy in nats/token, not exponentiated perplexity; throughout the paper we therefore call them \emph{negative log-likelihood} (NLL). Needle accuracy is greedy per-digit accuracy over the five target digits.

\subsection{Stage II: Matched 10B-Token Comparison}
The main comparison fixes the selected recipe---memory on, global attention, no distractor, baseline regularization---and changes only the attention core among NoPE, RoPE, and Polar. Each model trains for 18,722 steps of 524,288 tokens (9.816B tokens) at sequence length 2,048. Their parameter counts are 378.18M, 378.16M, and 378.22M, respectively. All three use the same data, tokenizer, Muon/AdamW recipe, training budget, NVIDIA L40S device class, and software environment. This is the controlled attention comparison.

We additionally train Raven Native (388.54M) and an Atma-Raven-Titans hybrid (382.37M) with the same tokenizer, data, sequence length, token budget, L40S device class, and software environment. Raven serves as our state-of-the-art stateful sub-quadratic baseline: because Raven advances beyond foundational state-space models (Mamba, S4, Gated DeltaNet) by integrating sparse routed memory, Mamba2 decay, and Swish feature maps~\citep{raven2026}, comparing against Raven provides a far stronger benchmark of sub-quadratic recurrent state capabilities than plain Mamba or un-routed linear recurrences. Raven uses its native AdamW optimizer rather than Muon because Muon's matrix-orthogonalization updates fail to converge on Raven's sparse routed recurrent state parameters (as archived in \texttt{archive/logs/raven\_native\_muon...}, where Muon caused loss explosion from step 750 onward to $6.88$ nats validation NLL and 0\% retrieval accuracy). Thus, Raven relies on its native AdamW recipe, changing both architecture family and optimizer; we report Raven as a strong model-scale baseline rather than an attention-only ablation.

\subsection{Evaluation Matrix and Open Log Artifacts}
The five promoted checkpoints, along with 10 pretrained open baseline models, are evaluated with checkpoint-exact forward paths. All raw execution outputs, console logs, and benchmark matrix JSON payloads are committed and archived in the repository for full auditability, and their full tabular outputs are presented in the Appendix:
\begin{itemize}
    \item \textbf{120-cell 1B factorial sweep logs} (Appendix~\ref{appendix:full_ablation}): Full 1B-token training trajectories and 2K--64K evaluations across 120 factorial configurations (3 attention cores $\times$ 5 regularization modes $\times$ distractor ON/OFF $\times$ memory ON/OFF $\times$ window ON/OFF).
    \item \textbf{24,000-trial retrieval depth sweep} (Appendix~\ref{appendix:long_context_matrix}): passkey and NIAH over synthetic and real FinePDFs haystacks, lengths 2K--256K, depths 10/50/90\%, and 50 paired trials per cell. The primary metric is teacher-forced five-token accuracy; exact-value accuracy and NLL are also archived.

\begin{itemize}

However, because Raven's lossy compression starts at a lower initial 2K baseline (41.1\% vs 98.9\%), Polar maintains a superior Pareto balance for soft-attentional retrieval fidelity across all sequence lengths out to 256K.
\end{itemize}

\paragraph{Zero-Shot Extrapolation Expectations and Polar's 64K Milestone.}
As shown in Table~\ref{table:synthetic_vs_real_retrieval}, reaching 0.3\% accuracy at 256K on natural text haystacks is an \emph{expected baseline result} for un-adapted $128\times$ zero-shot sequence length extension ($2\text{K} \to 256\text{K}$). By contrast, Polar Attention extends high-fidelity soft-attentional retrieval on natural text texts far beyond its training window:
\begin{itemize}
    \item \textbf{16.3\% Real-Text Retrieval Milestone at 64K:} At sequence length 64K ($32\times$ pretraining sequence extension), Polar is the \emph{only architecture} that preserves double-digit retrieval accuracy on natural text at \textbf{16.3\%}, whereas NoPE (0.0\%) and RoPE (0.0\%) have suffered total collapse, and recurrent models are reduced to low single digits (Raven Native at 2.9\%, Atma-Raven-Titans at 0.5\%).

    \item \textbf{Key-Vector Entropy Discrepancy:} In synthetic filler (lorem ipsum), key vectors remain orthogonal or low-entropy, enabling Polar's extreme-value null sink $\mathrm{null}_i = \mathrm{null\_base} + \mathrm{softplus}(\gamma)\sqrt{\ln n_i}$ to maintain \textbf{68.4\%} retrieval at 256K ($128\times$ pretraining context). In natural text, dense clusters of semantically active distractor keys accumulate background entropy that crosses the null sink floor at extreme 128K--256K lengths, highlighting key-density semantic interference as the primary boundary for un-adapted long-context extrapolation.
\end{itemize}

\subsubsection{Geometric Regularization Trade-off and Long-Document Stability}
Polar's modest ~1.5\% short-context expressivity penalty arises directly from radial unit normalization ($\mathbf{c}_i = \mathbf{s}_i / \|\mathbf{s}_i\|_2$). Standard unconstrained softmax attention permits query-key logit norms to grow arbitrarily large, expressing extremely sharp, high-peaked output distributions optimal for short 2K context completion. By contrast, radial unit normalization constrains direction vectors onto the unit hypersphere $\|\mathbf{c}_i\|_2 \le 1$. This acts as a structural geometric regularizer: it slightly constrains short-sequence logit sharpness in exchange for completely bounding energy growth and preventing catastrophic representation collapse at 256K lengths.

This trade-off is strongly validated by long-document bits-per-byte (BPB) stability across 256K extensions (Table~\ref{table:long_context_summary}). While NoPE undergoes severe loss degradation with a $5.65\times$ BPB inflation (1.432 to 8.097 BPB) and RoPE degrades by $1.75\times$ (1.439 to 2.512 BPB), Polar degrades by only $1.26\times$ (1.451 to 1.825 BPB), demonstrating superior language modeling fidelity on extended texts (including PG-19 and Proof-Pile controls).

\subsubsection{Serving Latency Scaling and Roofline Analysis}
Serving performance measurements across context lengths from 2K to 128K on one NVIDIA L40S GPU (Table~\ref{table:quality_efficiency} and Figure~\ref{fig:serving_scaling}) illustrate distinct operational roofline regimes:
\begin{enumerate}
    \item \textbf{Prefill Scaling (Compute-Bound Roofline):} As illustrated in Figure~\ref{fig:serving_scaling}a, matrix multiplications ($Q K^\top$, MLPs) during prefill have high operational intensity ($\mathrm{FLOPs}/\mathrm{Byte} \gg 1$), running in the compute-bound regime on NVIDIA L40S (916 TFLOPS BF16). At sequence length 16K, Polar prefill reaches peak efficiency at \textbf{161,550 tokens/second} (0.101s prefill time). At 128K context, prefill time is 1.62s for Polar, 1.47s for NoPE/RoPE, and 1.00s for Atma-Raven-Titans. Fused Triton streaming keeps peak memory at 39.4 GiB across all lengths, matching production FlashAttention efficiency.
    \item \textbf{Decoding Scaling (Memory-Bandwidth-Bound Roofline):} As shown in Figure~\ref{fig:serving_scaling}b, single-sequence decoding (batch size 1) requires reading KV cache buffers from HBM to SRAM, operating in the memory-bandwidth-bound regime (L40S 864 GB/s HBM3). For attention models (Polar, NoPE, RoPE), decode latency scales linearly with context length due to $O(L)$ KV cache HBM reads: 2.27ms/token at 2K $\to$ 3.70ms at 16K $\to$ 5.66ms at 32K $\to$ 9.22ms at 64K $\to$ \textbf{16.30ms/token} at 128K.
    \item \textbf{Recurrent Raven Constant Latency:} Recurrent Raven maintains a fixed $O(1)$ state size ($M_t \in \mathbb{R}^{d_v \times d_k}$), bypassing KV cache HBM reads during decode. Consequently, Atma-Raven-Titans maintains a \textbf{flat 2.27ms/token} decode latency (440.3 tokens/s) from 2K to 128K context (Figure~\ref{fig:serving_scaling}b), running $7.2\times$ faster than attention models at 128K.
\end{enumerate}

\subsubsection{Structural Stress Analogy to Finite Element Analysis (FEA)}
In structural engineering, Finite Element Analysis (FEA) subjects a physical structure to increasing mechanical load $P$ to identify stress concentration nodes, locate the \emph{yield point} $\sigma_y$ (elastic operating limit), and predict structural failure. In long-context sequence modeling, extending context length $L \in [2\mathrm{K}, 256\mathrm{K}]$ acts as an increasing \emph{information load}. Our \texttt{StressProbe} functions as a multi-node strain gauge grid attached to every transformer block $i \in \{0, \dots, 15\}$, recording internal activation moments (RMS stress) and local secant gains $G_i$ (local operator stiffness):
\begin{equation}
    G_i = \frac{\|f_i(x + \delta x) - f_i(x)\|_{\mathrm{rms}}}{\|\delta x\|_{\mathrm{rms}}}, \quad \text{where } \|\delta x\|_{\mathrm{rms}} = 0.02 \cdot \|x\|_{\mathrm{rms}} \text{ under isotropic } d \sim \mathcal{N}(0, I).
\end{equation}
The maximum sampled secant gain $G_{\mathrm{max}}$ provides a tight empirical lower bound on the local block Lipschitz constant.

\subsubsection{Yield Locus and Architectural Weak Point}
The FEA heatmap visualization in Figure~\ref{fig:stress_heatmap} displays the raw $16 \times 8$ secant gain data across sequence lengths and localizes three distinct structural behaviors:
\begin{enumerate}
    \item \textbf{Polar (Internal Energy Damper):} Clean NLL remains flat (1.275 at 128K $\to$ 1.292 at 256K). Maximum block secant gain declines smoothly from 1.427 to 1.369, and attention-projection RMS remains stable. Unbounded participation growth $n_{\mathrm{eff}}$ is absorbed internally by radial unit normalization ($\|c_i\|_2 \le 1$) and bounded $\mathrm{tanh}$ magnitude ($\mathrm{mag}_i \in [0, 1)$), acting like an internal energy-dissipating damper that prevents structural yield across 256K contexts.
    \item \textbf{RoPE (Representational Attenuation):} NLL degrades smoothly (1.950 to 2.846). Block secant gain falls alongside shrinking MLP and residual RMS signals, signaling positional frequency domain mismatch and representational attenuation rather than noise amplification.
    \item \textbf{NoPE (Unstable Yield Locus):} NLL explodes to 10.766 at 256K. As displayed in Figure~\ref{fig:stress_heatmap}, the FEA probe localizes the structural \textbf{yield locus / weak point} to a specific depth chain:
    \begin{equation}
        \underbrace{\text{Block 6 Attn}}_{\text{Initial Stress Concentration}} \longrightarrow \underbrace{\text{Block 7 MLP}}_{\text{Shear Amplification ($G=1.376$)}} \longrightarrow \underbrace{\text{Block 10 Attn}}_{\text{Structural Buckling}}
    \end{equation}
    Block 6 Attention acts as the initial stress concentration node; Block 7 MLP accelerates the response gain (rising from 1.018 at 2K to 1.376 at 256K); and Block 10 Attention experiences catastrophic activation explosion down the residual backbone, causing NLL collapse.
\end{enumerate}

\subsection{Environment Sensitivity and Pretraining Indistinguishability}
A striking empirical finding in our diagnostic logs is that \textbf{short-context pretraining convergence alone provides zero warning signal for long-context extrapolation collapse}.

As illustrated in Figure~\ref{fig:nope_pretrain_loss}, during 2K-context pretraining across 10B tokens, all three NoPE variants achieve virtually identical, statistically indistinguishable validation loss trajectories:
\begin{itemize}
    \item \textbf{NoPE (L4 mbs4 Control):} 1.9011 nats pretraining loss at 2K ($2.8161$ nats validation loss at step 18,722).
    \item \textbf{NoPE (L40S mbs16 Promoted):} 1.8900 nats pretraining loss at 2K ($2.8126$ nats validation loss at step 18,722).
    \item \textbf{NoPE (L40S mbs4 Control):} 1.8804 nats pretraining loss at 2K ($2.8128$ nats validation loss at step 18,722).

Even when zoomed in to 0.001-nat resolution (Figure~\ref{fig:nope_pretrain_loss}b), the pretraining loss curves are completely overlapping ($<0.01\%$ relative difference).

\begin{itemize}
    \item \textbf{NoPE (L4 mbs4 Control):} Extrapolates stably at 256K context (4.0668 nats NLL), with Block 7 secant gain remaining flat at $1.014$.
    \item \textbf{NoPE (L40S mbs16 Promoted):} Suffers catastrophic activation explosion at 256K context (10.7659 nats NLL), with Block 7 secant gain surging to $1.376$.
    \item \textbf{NoPE (L40S mbs4 Control):} Suffers near-identical activation explosion at 256K context (9.9048 nats NLL), with Block 7 secant gain surging to $1.401$.
\end{itemize}

\subsubsection{The Empirical Diagnostic Journey: From L4 to L40S}
The discovery of this environment sensitivity followed a systematic diagnostic sequence:
\begin{enumerate}
    \item \textbf{Initial 1B Sweeps and 10B Control on L4:} We executed all Stage~I 1B-token ablation sweeps on NVIDIA L4 (24GB) GPUs. We then trained our first Stage~II 10B NoPE control model on L4 using microbatch size 4 (\texttt{mbs4}), observing solid $2\text{K} \to 256\text{K}$ extrapolation ($4.07$ nats NLL at 256K).
    \item \textbf{Transition to L40S and Unexpected Extrapolation Divergence:} To accelerate the remaining 10B comparisons, we transitioned our primary training infrastructure to NVIDIA L40S (48GB) GPUs and trained the promoted NoPE checkpoint using microbatch size 16 (\texttt{mbs16}). Surprisingly, while 2K pretraining validation loss curves were virtually identical ($2.8126$ vs $2.8161$ nats, $<0.01\%$ difference; Figure~\ref{fig:nope_pretrain_loss}), the L40S \texttt{mbs16} checkpoint suffered catastrophic 256K extrapolation collapse ($10.77$ nats NLL).
    \item \textbf{Systematic Diagnostic Elimination:} We systematically investigated potential causal factors:
    \begin{itemize}
        \item \emph{Evaluation Environment / PyTorch Version?} Re-evaluating L4 and L40S checkpoints under PyTorch 2.12 versus 2.13 yielded identical scores, ruling out evaluation software differences.
        \item \emph{Microbatch Accumulation Size?} Retraining NoPE on L40S with \texttt{mbs4} produced near-identical 256K activation explosion ($9.90$ nats NLL), proving microbatch size alone was not the cause.
        \item \emph{Deterministic Stream Fixtures?} Running deterministic synthetic stream fixtures (\texttt{scripts/diagnose\_training\_artifact.py}) across PyTorch versions and microbatch sizes showed no gradient or loss divergence at 2K.
    \end{itemize}
    We concluded that reproducing the exact L4 \texttt{mbs4} pretraining weight trajectory on L40S involves low-level non-deterministic CUDA kernel reduction and floating-point accumulation order across GPU architectures.
\end{enumerate}

\subsubsection{Fairness of the Main Comparison and a Methodological Audit Call}
Crucially, \textbf{all five headline Stage~II 10B models (NoPE, RoPE, Polar, Atma-Raven-Titans, and Raven Native) were trained in the exact same L40S hardware and software environment}. If GPU-level kernel reduction order introduced an implicit numerical regularization challenge during pretraining, Polar was subjected to the exact same environment and successfully absorbed context extensions out to 256K ($1.825$ BPB vs $10.77$ NoPE), establishing a strictly controlled and fair comparison.

These empirical findings carry major methodological implications for the broader long-context research community. In many long-context extrapolation studies, an architecture's failure or success at extended contexts ($8\text{K} \to 256\text{K}$) is attributed entirely to its high-level mathematical design (e.g., positional embeddings, norm types, attention scaling). Our controlled diagnostics demonstrate that \textbf{low-level hardware execution order alone can completely alter long-context extrapolation trajectories} without leaving any detectable trace in short-context pretraining loss curves. We therefore issue an explicit audit call to long-context researchers: \textit{claims regarding architecture-driven extrapolation failures or successes must be audited across multiple hardware device classes and microbatch execution environments before attributing results solely to architectural mechanics.}

\FloatBarrier
\subsection{Implementation Notes}
Polar's participation ratio requires streaming both the softmax denominator $L$ and squared denominator $Q^2$. When the online maximum changes by $\alpha=\exp(M_{\mathrm{old}}-M_{\mathrm{new}})$, the fused Triton kernel rescales $L$ and the value sum by $\alpha$, but $Q^2$ by $\alpha^2$, recovering $n_{\mathrm{eff}}=L^2/Q^2$ without materializing the $T\times T$ score matrix. The paged decode kernel groups the four query heads sharing each KV head, and the gated-delta kernel updates recurrent state in place. These kernels make the 256K evaluations feasible, but Table~\ref{table:quality_efficiency} deliberately reports end-to-end backend-inclusive measurements rather than attributing all performance to one kernel.

\section{Conclusion}
This work frames long-context sequence modeling not as a search for a single universal architecture, but as an empirical Pareto frontier balancing soft retrieval fidelity, reasoning capacity, long-document likelihood stability, and inference compute efficiency. Across matched 10B-token training runs, Polar Attention establishes a compelling Pareto balance by preserving soft-attentional retrieval fidelity (16.3\% real-text accuracy at 64K vs 0.0\% for NoPE/RoPE) and long-document stability (1.26$\times$ BPB inflation at 256K) at a modest ~1.5\% short-context expressivity trade-off. Meanwhile, stateful Raven models offer $O(1)$ recurrent memory that excels at multi-step reasoning (46\% BABILong at 256K) and $7.2\times$ faster decode throughput, and standard Softmax retains a minor edge on short 2K completion tasks.

Crucially, our diagnostic stress analysis uncovers a striking empirical warning: short-context pretraining convergence is completely blind to long-context extrapolation collapse, with identical 2K pretraining validation loss trajectories masking radical 256K context divergences across hardware device classes (L4 vs L40S) due to CUDA kernel reduction order. We issue a call to action for the field to adopt multi-hardware environment auditing protocols alongside architectural reporting. By releasing our complete repository artifact, configs, logs, and diagnostic suites, we aim to establish a transparent baseline for auditable, multi-objective long-context sequence modeling research.

\section{Theoretical Framing}
\label{appendix:theory}

This appendix analyzes the role of the extreme-value-corrected null sink and the bounded
ATMA mixer. The statements are sufficient-condition results: they establish noise-odds and
norm bounds under explicit distributional and bounded-state assumptions, but they do not
establish distributional invariance or replace the empirical ablation evidence in Section~4.

\subsection{Extreme-Value Null Floor}

Fix one query and let $X_j$ denote the score of an irrelevant key after the same normalization
used by Polar Attention. The TDA analysis motivates the following noise model.

\begin{assumption}[Sub-Gaussian noise scores]
For irrelevant keys $j \in \mathcal{N}_n$, $|\mathcal{N}_n| \le n$, the scores are mean-zero
and $v^2$-sub-Gaussian for some $v>0$:
\begin{equation}
    \mathbb{E}\exp(tX_j) \le \exp\left(\frac{v^2 t^2}{2}\right)
    \quad \text{for all } t \in \mathbb{R}.
\end{equation}
\end{assumption}

Polar uses a learned floor of the form
\begin{equation}
    \nu_n = b + s\sqrt{\log(n+1)}, \qquad b \ge 0,\quad s \ge 0,
\end{equation}
where $b$ corresponds to \texttt{null\_base} and $s$ to the positive learned null-slope.
The implementation does not constrain the learned base to remain nonnegative, so the results
below apply to trained heads for which $b\ge0$; alternatively, a nonnegative parameterization
of \texttt{null\_base} would enforce this condition.
The next proposition is the direct analogue of the TDA survivor-count bound, with the
hard threshold replaced by the Polar null floor.

\begin{proposition}[Noise exceedances above the Polar null floor]
Under Assumption~1, the expected number of irrelevant keys whose score exceeds $\nu_n$ is
\begin{equation}
    \mathbb{E}\left[\sum_{j \in \mathcal{N}_n} \mathbf{1}\{X_j > \nu_n\}\right]
    \le
    n \exp\left(-\frac{\nu_n^2}{2v^2}\right).
\end{equation}
In particular, if $s \ge \sqrt{2}\,v$, this expectation is $O(1)$; if
$s > \sqrt{2}\,v$, it decays polynomially in $n$.
\end{proposition}

\begin{proof}
For each irrelevant key, sub-Gaussian concentration gives
$\Pr[X_j > \nu_n] \le \exp(-\nu_n^2/(2v^2))$. Summing this tail probability over at most
$n$ irrelevant keys proves the bound. If $b \ge 0$, then
$\nu_n^2 \ge s^2\log(n+1)$, so the right-hand side is at most
$n(n+1)^{-s^2/(2v^2)}$, which is bounded when $s^2/(2v^2)\ge 1$ and decays when the
inequality is strict.
\end{proof}

\subsection{Soft Null-Sink Odds}

Unlike TDA, Polar does not discard sub-threshold keys. It appends the null floor as a softmax
competitor. For $n\ge2$, let
\begin{equation}
    \theta_n = 1 + a\log n, \qquad a \ge 0,
\end{equation}
be the length temperature and define the real-noise-to-null odds
\begin{equation}
    R_n = \sum_{j\in\mathcal{N}_n}\exp\left(\theta_n(X_j-\nu_n)\right).
\end{equation}
Then $R_n$ is exactly the ratio between the unnormalized softmax mass assigned to irrelevant
real keys and the unnormalized mass assigned to the null sink, restricted to noise keys.

\begin{proposition}[Null odds vanish under an extreme-value margin]
Suppose that, for some constants $c$ and $s$ with $s>c>\sqrt{2}\,v$, the learned null floor
has $\nu_n=s\sqrt{\log(n+1)}$ up to a nonnegative offset. With probability tending to one,
\begin{equation}
    R_n \le
    n\exp\left(-(1+a\log n)(s-c)\sqrt{\log n}\right).
\end{equation}
If $a>0$, this upper bound converges to zero faster than any inverse polynomial in $n$.
\end{proposition}

\begin{proof}
By the same union bound as Proposition~1,
\begin{equation}
    \Pr\left[\max_{j\in\mathcal{N}_n} X_j > c\sqrt{\log(n+1)}\right]
    \le n(n+1)^{-c^2/(2v^2)} \to 0,
\end{equation}
because $c>\sqrt{2}\,v$. On the complementary event, every irrelevant score is at least
$(s-c)\sqrt{\log n}$ below the null floor, hence each summand in $R_n$ is at most
$\exp(-(1+a\log n)(s-c)\sqrt{\log n})$. Summing over at most $n$ noise keys gives the
displayed bound. For $a>0$, the logarithm of the bound is
$\log n-a(s-c)(\log n)^{3/2}+O(\sqrt{\log n})$, which tends to $-\infty$ faster than
$-\rho\log n$ for any fixed $\rho$.
\end{proof}

This result is the theoretical bridge from TDA to Polar: TDA enforces the extreme-value
threshold by hard sparsification, while Polar uses the same scaling to make the null sink
win the softmax competition against pure background noise.

\subsection{Bounded Direction and Magnitude Channels}

\begin{proposition}[Polar readout is radially normalized and bounded]
For the implementation-level normalization with $\varepsilon>0$, define
\begin{equation}
    s_i = \sum_j w_{ij}v_j + w_{iN}v_{\mathrm{null}},
    \qquad
    c_i = \frac{s_i}{\max(\lVert s_i\rVert_2,\varepsilon)}.
\end{equation}
Then $\lVert c_i\rVert_2\le1$, with equality whenever
$\lVert s_i\rVert_2\ge\varepsilon$. The magnitude channel
\begin{equation}
    \mathrm{mag}_i =
    \tanh\left(\beta\log(1+m_{\mathrm{eff},i})\right)
\end{equation}
lies in $[0,1)$ for $\beta\ge0$ and all $m_{\mathrm{eff},i}\ge0$. If the normalized
real-key distribution is exactly uniform on a support of $m$ keys, its participation ratio is
$n_{\mathrm{eff}}=m$.
\end{proposition}

\begin{proof}
The norm bound follows directly from the denominator. The magnitude bound follows
from $\log(1+m_{\mathrm{eff},i})\ge0$ and $\tanh(x)\in[0,1)$ for finite $x\ge0$. For $m$
equally weighted real keys, $\hat{w}_{ij}=1/m$ on the support, so
$n_{\mathrm{eff}}=1/\sum_{j=1}^{m}(1/m)^2=m$.
\end{proof}

Thus the content channel removes radial scale while the magnitude channel exposes a bounded
summary of effective match count. This is a channel-level decomposition, not a claim that
$c_i$ is generally independent of count: changing the real-key mixture or its balance with a
nonzero learned $v_{\mathrm{null}}$ can rotate the direction.

\subsection{Bounded Recurrent Memory State}

The recurrent memory branch is also bounded under standard normalized-key and contractive-gate
conditions. Consider the gated-delta update used by ATMA:
\begin{equation}
    M_t = \gamma_t M_{t-1}(I-\beta_t k_tk_t^\top) + \beta_t v_tk_t^\top .
\end{equation}

\begin{assumption}[Contractive memory update]
For all $t$, $\lVert q_t\rVert_2=\lVert k_t\rVert_2=1$, $\lVert v_t\rVert_2\le V$, $0\le\beta_t\le1$, and
$0\le\gamma_t\le\bar{\gamma}<1$.
\end{assumption}

\begin{proposition}[Gated-delta state norm is length-bounded]
Under Assumption~2,
\begin{equation}
    \lVert M_t\rVert_F
    \le
    \bar{\gamma}^t\lVert M_0\rVert_F + \frac{V}{1-\bar{\gamma}} .
\end{equation}
\end{proposition}

\begin{proof}
Since $\lVert k_t\rVert_2=1$ and $0\le\beta_t\le1$, the matrix
$I-\beta_t k_tk_t^\top$ has spectral norm at most one. Also
$\lVert \beta_t v_tk_t^\top\rVert_F \le V$. Therefore
$\lVert M_t\rVert_F\le \bar{\gamma}\lVert M_{t-1}\rVert_F+V$. Unrolling this scalar
recurrence proves the bound.
\end{proof}

\begin{corollary}[ATMA mixer is bounded under fixed weights]
Under the conditions above, and for fixed projection operator norms, the per-layer ATMA
mixing output
\begin{equation}
    \mathbf{out}=\mathbf{content}+\mathbf{count}+\mathbf{memory}
\end{equation}
is bounded independently of sequence length.
\end{corollary}

\begin{proof}
The content channel is a projection of head directions with norm at most one multiplied by
sigmoid gates,
the count channel is a projection of magnitudes in $[0,1)$, and the memory readout is bounded
by Proposition~4 and the fixed readout projection norms. The sum of finitely many bounded
terms is bounded independently of $n$.
\end{proof}

\subsection{Scope of the Machine-Checked Artifact}

The accompanying Lean artifact machine-checks the finite-sum, exponential-monotonicity,
bounded-channel composition, and invariant-set induction steps used above. The sub-Gaussian
tail inequality, the high-probability extreme-value margin, and the one-step matrix contraction
are supplied to Lean as premises rather than derived from measure-theoretic random variables
and the implemented gated-delta recurrence. We therefore describe it as a machine-checked
proof skeleton, not an end-to-end formal verification of the ATMA method. The learned
conditions $b\ge0$ and $s>c>\sqrt{2}v$ are sufficient conditions and are not asserted to hold
for every trained head without an empirical parameter-and-score audit.

\label{appendix:polar_algorithms}

\subsection{Naive Materialized PyTorch Reference}

\begin{lstlisting}[language=Python, caption={Materialized PyTorch reference for Polar Attention.}, label={lst:polar_pytorch}]
def polar_reduce(sigma, v, n_keys, *, v_null, null_base,
                 null_slope_raw, len_gain_raw, mag_beta_raw,
                 eps=1e-6):
    """Reference oracle. sigma: (B,H,Tq,Tk), v: (B,H,Tk,dk)."""
    out_dtype = v.dtype
    cd = torch.float32 if v.dtype in (torch.float16, torch.bfloat16) else v.dtype
    B, H, Tq, Tk = sigma.shape
    dk = v.shape[-1]
    sigma, v = sigma.to(cd), v.to(cd)

    n = n_keys.to(cd).clamp(min=1.0)
    temp = 1.0 + F.softplus(len_gain_raw.to(cd)).view(1, H, 1, 1) \
        * torch.log(n).view(1, 1, Tq, 1)
    null = null_base.to(cd).view(1, H, 1, 1) \
        + F.softplus(null_slope_raw.to(cd)).view(1, H, 1, 1) \
        * torch.sqrt(torch.log(n + 1.0)).view(1, 1, Tq, 1)

    # Scale finite entries, then re-apply the mask. This avoids NaNs from
    # differentiating through temp * (-inf).
    masked = torch.isneginf(sigma)
    sigma_safe = torch.where(masked, torch.zeros_like(sigma), sigma)
    real = (sigma_safe * temp).masked_fill(masked, float("-inf"))

    logits = torch.cat([real, null.expand(B, H, Tq, 1) * temp], dim=-1)
    w = torch.softmax(logits, dim=-1)
    w_r = w[..., :-1]
    w_null = w[..., -1:]

    # Direction channel: convex value mix plus learned null vector, projected
    # radially so the content channel has bounded norm.
    s = torch.matmul(w_r, v) + w_null * v_null.to(cd).view(1, H, 1, dk)
    c = F.normalize(s, p=2, dim=-1, eps=eps)

    # Magnitude channel: inverse Simpson participation ratio over real keys,
    # gated by non-null confidence and squashed to [0, 1).
    denom = w_r.sum(-1, keepdim=True).clamp_min(eps)
    w_hat = w_r / denom
    n_eff = 1.0 / w_hat.square().sum(-1).clamp_min(eps)
    m_eff = n_eff * (1.0 - w_null.squeeze(-1))
    beta = F.softplus(mag_beta_raw.to(cd)).view(1, H, 1)
    mag = torch.tanh(beta * torch.log1p(m_eff))

    return c.to(out_dtype), mag.to(out_dtype)
\end{lstlisting}

\subsection{Flash-Style Triton Forward Kernel}
Code~\ref{lst:polar_triton} lists the Triton streaming forward pass. Note that the Triton magnitude computation uses the hyperbolic identity $2\sigma(2x) - 1 \equiv \tanh(x)$, where $\text{beta}$ is pre-transformed via $\text{softplus}(\cdot)$ upon loading, ensuring exact algebraic equivalence with the PyTorch reference implementation (\texttt{torch.tanh(beta * torch.log1p(m\_eff))}).

\begin{lstlisting}[language=Python, caption={Core Triton streaming forward pass. The full kernel includes pointer arithmetic, launch metadata, and backward kernels.}, label={lst:polar_triton}]
@triton.jit
def _polar_fwd_kernel_core(q, K, V, VNULL, SPG, NULLBASE, SPS, BETA,
                           n_i, h, Tk, scale, eps,
                           BLOCK_N: tl.constexpr, DK: tl.constexpr,
                           WINDOW: tl.constexpr):
    # Per-query length temperature and extreme-value-corrected null floor.
    if WINDOW > 0:
        n_count = tl.maximum(tl.minimum(n_i, float(WINDOW)), 1.0)
    else:
        n_count = tl.maximum(n_i, 1.0)
    temp = 1.0 + tl.load(SPG + h).to(tl.float32) * tl.log(n_count)
    nullv = tl.load(NULLBASE + h).to(tl.float32) \
        + tl.load(SPS + h).to(tl.float32) * tl.sqrt(tl.log(n_count + 1.0))
    beta = tl.load(BETA + h).to(tl.float32)

    # Online softmax state. Q2 is the extra accumulator needed for the
    # participation ratio; it rescales by alpha**2 under max-shift updates.
    m_i = tl.full([BLOCK_M], -1e38, tl.float32)
    l_i = tl.zeros([BLOCK_M], tl.float32)
    q2_i = tl.zeros([BLOCK_M], tl.float32)
    acc = tl.zeros([BLOCK_M, DK], tl.float32)

    for start_n in range(0, Tk, BLOCK_N):
        offs_n = start_n + tl.arange(0, BLOCK_N)
        k = load_key_block(K, offs_n)      # (BLOCK_N, DK), native dtype
        v = load_value_block(V, offs_n)    # (BLOCK_N, DK), native dtype

        sig = tl.dot(q, tl.trans(k)) * scale
        a = sig * temp[:, None]
        valid = offs_n[None, :] < n_i[:, None]
        if WINDOW > 0:
            valid = valid & (offs_n[None, :] >= (n_i[:, None] - WINDOW))
        a = tl.where(valid, a, -1e38).to(tl.float32)

        m_new = tl.maximum(m_i, tl.max(a, 1))
        alpha = tl.exp(m_i - m_new)
        p = tl.exp(a - m_new[:, None])
        p = tl.where(valid, p, 0.0)

        l_i = l_i * alpha + tl.sum(p, 1)
        q2_i = q2_i * alpha * alpha + tl.sum(p * p, 1)
        acc = acc * alpha[:, None] + tl.dot(p, v)
        m_i = m_new

    # Fold the virtual null sink as one additional softmax entry.
    a_null = temp * nullv
    m_new = tl.maximum(m_i, a_null)
    alpha = tl.exp(m_i - m_new)
    l_i = l_i * alpha
    q2_i = q2_i * alpha * alpha
    acc = acc * alpha[:, None]
    m_i = m_new
    p_null = tl.exp(a_null - m_i)
    Z = l_i + p_null

    v_null = tl.load(VNULL + h * DK + tl.arange(0, DK)).to(tl.float32)
    s = acc + p_null[:, None] * v_null[None, :]
    c = s / tl.maximum(tl.sqrt(tl.sum(s * s, 1)), eps)[:, None]

    n_eff = l_i * l_i / tl.maximum(q2_i, eps)
    m_eff = n_eff * (l_i / tl.maximum(Z, eps))
    mag = 2.0 * tl.sigmoid(2.0 * beta * tl.log(1.0 + m_eff)) - 1.0

    store_direction(c)
    store_magnitude(mag)
    save_for_backward(m_i, l_i, q2_i, s)
\end{lstlisting}

Listing~\ref{lst:diag_harness} provides the core Python implementation for tracking gradient and parameter signatures across microbatch sizes and PyTorch versions (\texttt{scripts/diagnose\_training\_artifact.py}).

\begin{lstlisting}[language=Python, caption={Core gradient and parameter vector signature tracking for accumulation divergence analysis.}, label={lst:diag_harness}]
def _is_critical(name: str) -> bool:
    return (
        ".attn.mem." in name
        or any(token in name for token in (
            "len_gain_raw", "null_base", "null_slope_raw", "mag_beta_raw", 
            "v_null", "mu_proj", ".attn.q.", ".attn.k.", ".attn.v.", 
            ".attn.canon_", ".attn.proj.",
        ))
    )

def _vector_payload(tensor: torch.Tensor) -> dict:
    flat = tensor.detach().float().reshape(-1).cpu()
    if flat.numel() <= CRITICAL_FULL_LIMIT:
        values = flat.tolist()
        mode = "full"
    else:
        count = min(CRITICAL_SAMPLE_SIZE, flat.numel())
        indices = torch.linspace(0, flat.numel() - 1, steps=count, dtype=torch.float64).round().long()
        values = flat[indices].tolist()
        mode = "sample"
    return {
        "mode": mode,
        "numel": flat.numel(),
        "values": values,
        "norm": torch.linalg.vector_norm(flat).item(),
        "max_abs": flat.abs().max().item() if flat.numel() else 0.0,
        "sum": flat.sum().item(),
        "finite": bool(torch.isfinite(flat).all()),
    }

def _tensor_signatures(model, gradients: bool) -> dict:
    groups = {}
    critical = {}
    for name, parameter in model.named_parameters():
        tensor = parameter.grad if gradients else parameter.data
        if tensor is None:
            continue
        detached = tensor.detach().float()
        group_name = _parameter_group(name)
        accumulator = groups.setdefault(
            group_name, {"sumsq": 0.0, "sum": 0.0, "max_abs": 0.0, "numel": 0, "finite": True}
        )
        accumulator["sumsq"] += detached.square().sum().item()
        accumulator["sum"] += detached.sum().item()
        accumulator["max_abs"] = max(accumulator["max_abs"], detached.abs().max().item())
        accumulator["numel"] += detached.numel()
        accumulator["finite"] = accumulator["finite"] and bool(torch.isfinite(detached).all())
        if _is_critical(name):
            critical[name] = _vector_payload(detached)
    for accumulator in groups.values():
        accumulator["norm"] = math.sqrt(accumulator.pop("sumsq"))
    return {"groups": groups, "critical": critical}
