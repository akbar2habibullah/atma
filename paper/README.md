## Updating reported results

The ICLR source is canonical. After editing it, run the following from the
repository root to regenerate the data-backed tables and figures, then sync the
public arXiv wrapper:

```bash
python paper/generate_primary_tables.py
python paper/generate_re_evaluation_tables.py
python paper/generate_results_figure.py
python paper/generate_downstream_candle_figure.py
python paper/generate_nope_pretrain_loss_figure.py
python paper/generate_niah_heatmap_figure.py
python paper/generate_stress_heatmap_figure.py
python paper/generate_serving_scaling_figure.py
python paper/sync_arxiv.py
```

These commands summarize archived results; they do not train or evaluate models.
Figure generation requires `reportlab`. `sync_arxiv.py` preserves the public
author block and repository link while copying the shared manuscript, appendices,
bibliography, and figures. Edit shared prose in `iclr2027/` first.

The primary endpoint table, fresh-run endpoint table, and untouched retrieval
breakdowns are generated by `generate_primary_tables.py`. It rejects missing or
duplicate retrieval cells and excludes smoke runs. Check their freshness with:

```bash
python paper/generate_primary_tables.py --check
```

## Build

Build from each edition's directory so local inputs, styles, and figures resolve
consistently. With Tectonic:

```bash
cd paper/iclr2027
tectonic --keep-logs --keep-intermediates iclr2027_conference.tex
cd ../arxiv
tectonic --keep-logs --keep-intermediates atma_arxiv.tex
```

Alternatively, from `paper/iclr2027/`:

```bash
pdflatex iclr2027_conference.tex
bibtex iclr2027_conference
pdflatex iclr2027_conference.tex
pdflatex iclr2027_conference.tex
```

Use the analogous sequence with `atma_arxiv` from `paper/arxiv/`.
Both sources explicitly select T1 font encoding so the Times-family text fonts
also resolve under Tectonic. `paper/.gitattributes` marks PDFs as binary to prevent
Windows line-ending conversion from invalidating PDF byte offsets.

The current builds were checked with Tectonic 0.17.0. After rebuilding, inspect
both PDFs, confirm the ICLR main text ends by page 9, and check the logs for
unresolved references, missing glyphs, font substitutions, and overflowing boxes.
